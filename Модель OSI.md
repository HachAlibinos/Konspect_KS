## 1. Введение

**Модель OSI** — это справочная система (создана в 1983 г., стандартизирована ISO в 1984 г.), которая определяет, как компьютеры взаимодействуют в сети.

- **Важно:** В реальной жизни мы используем модель **TCP/IP**, а OSI — это теоретический эталон (фреймворк).

## 2. Семь уровней модели OSI

![[Pasted image 20260228090447.png]]

### 7. Прикладной уровень (Application Layer)

![[Pasted image 20260228090553.png]]

Уровень, с которым взаимодействуют приложения (но это не сами программы, а их протоколы).

- **Функция:** Обеспечение связи между ПО и сетью.
    
- **Примеры:** HTTP/HTTPS (браузеры), SMTP (почта), DNS (имена доменов).
    
- **Схема в статье:** _Application Layer Diagram_ (показывает взаимодействие пользователя с протоколами).
    

### 6. Уровень представления (Presentation Layer)

![[Pasted image 20260228090619.png]]

Отвечает за «перевод» данных в понятный приложению формат.

- **Шифрование/Дешифрование:** Работа TLS/SSL.
    
- **Сериализация:** Преобразование структур данных (например, объектов JS) в байты и обратно.
    
- **Сжатие:** Уменьшение объема данных для быстрой передачи.
    

### 5. Сеансовый уровень (Session Layer)

![[Pasted image 20260228090654.png]]

 Управление сессиями (соединениями).

- **Функции:** Открытие, поддержание и закрытие диалога между клиентом и сервером.
    
- **Реальность:** В современном стеке TCP/IP этот уровень часто «слит» с транспортным или прикладным.
    

### 4. Транспортный уровень (Transport Layer)



Определяет способ передачи данных. Здесь данные называются **Сегментами**. 
![[Pasted image 20260228090745.png]]

- **TCP (Transmission Control Protocol):** Надежный, гарантирует доставку без ошибок и в нужном порядке. Используется там, где важна точность (текст, файлы).
    
- **UDP (User Datagram Protocol):** Быстрый, но «ненадежный» (может терять пакеты). Идеален для стриминга видео и игр.
    

### 3. Сетевой уровень (Network Layer)

![[Pasted image 20260228090804.png]]

Отвечает за маршрутизацию между разными сетями. Данные называются **Пакетами**.

- **Главный протокол:** IP (Internet Protocol).
    
- **Функция:** Добавление метаданных (IP-адресов) для поиска пути от клиента к серверу.
    

### 2. Канальный уровень (Data-Link Layer)

![[Pasted image 20260228090831.png]]

Взаимодействие внутри локальной сети. Данные называются **Кадрами (Фреймами)**. Состоит из двух подуровней:

1. **LLC (Logical Link Control):** Обработка ошибок и управление потоком.
    
2. **MAC (Media Access Control):** Присвоение уникальных ID (MAC-адресов) сетевым картам.
    

### 1. Физический уровень (Physical Layer)


![[Pasted image 20260228090857.png]]

Уровень «железа». Передает «сырые» **Биты**.

- **Среда передачи:** Электричество (медный кабель), свет (оптоволокно), радиоволны (Wi-Fi).
    
- **Функция:** Преобразование кадров в электрические/оптические сигналы.
